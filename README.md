# Lait Starter

This repository contains a starter project for code written in the [Lait](https://github.com/gancherj/Lait) language. To run it, open this folder in Visual Studio Code and install the [Lean extension](https://github.com/leanprover/vscode-lean4), and navigate to `LaitStarter/Basic.lean`. 
Then, click on `Restart File` in Lean's dropdown menu (or press Cmd+Shift+X).
